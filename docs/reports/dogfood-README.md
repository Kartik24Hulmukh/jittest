# Dogfood Evidence Receipts: Defect D-1 Verification

This directory contains signed differential execution receipts generated by `jittest verify` on `jittest`'s own Defect D-1 (`COLLECTION_CATCH` fail-closed exit code invariant).

- **Base commit**: `8c753b6dc91b1d6b2f45eada46ba36fd82cb9e19` (pre-WO-19, where `COLLECTION_CATCH` exited with code 0).
- **Head commit**: `e2cd1672a62a9c5342d5f952a8be14c41a69859e` (current `main`, where `exit_code_for(COLLECTION_CATCH) == 1`).

   - **Verdict**: `inconclusive`

The candidate failed collection on base due to `ImportError: cannot import name 'exit_code_for'`, correctly triggering jittest's fail-closed collection guard rather than fabricating a verdict.

## Cryptographic Verification

Any third party can verify the Ed25519 signature and payload integrity offline without network access or dependencies:

```bash
# Verify Candidate A receipt
jittest verify-receipt receipts/dogfood/receipt-d1-candidate-a.json

# Verify Candidate B receipt
jittest verify-receipt receipts/dogfood/receipt-d1-candidate-b.json
```

Both receipts are signed with the Ed25519 private key and contain the public key and hex signature for independent audit.
